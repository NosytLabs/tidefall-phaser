2. World feels empty - needs more life/details

- Add weather particles

#### 3. Smallburg Asset Integration

- Better animations

#### 4. Lighting & Atmosphere
- Day/night cycle with lighting overlay
- Weather effects (rain, fog)
- Water reflections

#### 5. Advanced Systems (ralph-mode)
- Better NPC AI with state machines
- Quest system improvements
- Shop system with UI

### Implementation Order
1. Camera & viewport improvements
