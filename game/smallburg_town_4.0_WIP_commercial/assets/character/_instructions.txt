Instructions
========================



Base Information
----------------
All animations are separated by skin tone 

Movement animation will have 8 directions:
Left, right, up, down, left-down, right-down, right-up, left-up

Special animations like jumping, attacking or mining for example, will only have 4 directions.
left-down, right-down, right-up, left-up

In the folder separated_sheets, you can find all the animations separated into
each file. This is not recommended for usage in game development as loading each sheet
separately is not efficient.

In the folder full_sheets, you can find all the animations combined into
Single files for game import.

*_skin_*_animaton.png, contains all animations one direction per line.
*_skin_*_animaton_compact.png, contains all animations in a single line in a 16 column sheet

The compact version should be used for game development as it will have the most efficient 
usage of Memory when loading textures.


Pack info
----------------
There are four skin tones: light, medium, brown and dark
There are four animations: idle, walk, run and jump


Animations
----------------

Idle: 2 frames
Directions: 8
Speed: 500ms per frame

Walk: 4 frames
Directions: 8
Speed: 150 ms per frame

Run: 4 frames
Directions: 8
Speed: 150ms per frame

Jump: 6 frames
Directions: 4
Speed: 150ms per frame
